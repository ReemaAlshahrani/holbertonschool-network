# Networking basics #1

This project covers the fundamentals of networking, host configuration, network interfaces, and socket listening using basic Linux tools and Bash scripts.

## Files Description

| File Name | Description |
| --------- | ----------- |
| `0-change_your_home_IP` | Bash script that modifies `/etc/hosts` so that `localhost` resolves to `127.0.0.2` and `facebook.com` resolves to `8.8.8.8`. |
| `1-show_attached_IPs` | Bash script that displays all active IPv4 IP addresses on the machine. |
| `2-port_listening_on_localhost` | Bash script that listens on port `98` on localhost using netcat (`nc`). |
